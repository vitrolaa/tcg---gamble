# TCG Gamble / PokéVault

Um aplicativo web interativo estilo TCG (Trading Card Game) focado em colecionar cartas, gerenciar inventário, pescar itens, participar de gachas e testar a sorte em sistemas de upgrader de cartas inspirados em mecânicas clássicas de gamble.

---

## Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias modernas de front-end:

* React (com Vite para alta performance)
* Tailwind CSS (para estilização e design responsivo)
* Framer Motion (para animações fluidas)
* Lucide React (para ícones modernos)
* Canvas Confetti (para comemorações e efeitos visuais)

---

## Funcionalidades

* Álbum de Cartas: Visualize, organize e gerencie a sua coleção de cards de Pokémon.
* Sistema de Gacha: Abra pacotes/packs para conseguir novas cartas de diferentes raridades.
* Mini-game de Pesca: Pescagem de recursos e itens especiais dentro do jogo.
* Card Upgrader: Sistema dinâmico de melhoria de cartas com roleta/gauge de sucesso baseado em riscos e recompensas.
* Cassino & Economia: Ganhe moedas e gerencie seus recursos para investir na coleção.
* Conquistas & Missões: Complete objetivos para desbloquear recompensas exclusivas.
